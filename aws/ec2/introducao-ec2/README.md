# Introdução ao Amazon EC2
Projeto de estudo baseado no Lab 11 da Escola da Nuvem. 
O desafio é iniciar, proteger, monitorar, redimensionar e encerrar uma instância EC2 com um servidor web.

## Etapas do laboratório
* Criar a instância com Amazon Linux 2023 e proteção contra encerramento.
* Monitorar as verificações e métricas da instância.
* Ajustar o grupo de segurança para permitir acesso HTTP.
* Redimensionar a instância de t3.micro para t3.small e o volume EBS de 8 para 10 GiB.
* Testar a proteção e encerrar a instância.

## Segurança
O acesso HTTP aberto para qualquer IPv4 foi usado no laboratório; em outros ambientes, as regras devem ser avaliadas conforme a necessidade.
